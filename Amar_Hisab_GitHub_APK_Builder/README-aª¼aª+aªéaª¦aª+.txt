আমার হিসাব — অফলাইন Android অ্যাপের সোর্স প্রজেক্ট

ফিচার:
- আয় ও খরচ যোগ করা
- তারিখ, ক্যাটাগরি ও বিবরণ
- মোট আয়, মোট খরচ ও ব্যালেন্স
- তারিখ অনুযায়ী লেনদেন দেখা
- মাসিক সারাংশ
- CSV রিপোর্ট ডাউনলোড
- JSON Backup ও Restore
- ইন্টারনেট ছাড়াই কাজ করে; তথ্য ডিভাইসের স্থানীয় স্টোরেজে থাকে

APK তৈরি:
1. কম্পিউটারে Android Studio ইনস্টল করুন।
2. এই ZIP Extract করুন।
3. Android Studio থেকে Extract করা AmarHisab ফোল্ডার Open করুন।
4. Gradle Sync সম্পন্ন হতে দিন।
5. Build > Build Bundle(s) / APK(s) > Build APK(s) নির্বাচন করুন।
6. app/build/outputs/apk/debug/app-debug.apk ফাইলটি তৈরি হবে।

গুরুত্বপূর্ণ:
এই প্যাকেজটি Android Studio-তে APK তৈরির সোর্স প্রজেক্ট; এখানে সরাসরি APK বাইনারি কম্পাইল করা হয়নি।
ডেটা শুধু অ্যাপের নিজস্ব লোকাল স্টোরেজে থাকে। ফোন বদলানো বা অ্যাপের ডেটা মুছে ফেলার আগে Backup নিন।
